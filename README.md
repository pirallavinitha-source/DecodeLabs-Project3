# Vinitha Portfolio Website – Project 3

## Overview

This is a responsive personal portfolio website developed as part of DecodeLabs Frontend Development Project 3. The project showcases my educational background, technical skills, projects, and contact information while incorporating interactive JavaScript features.

## Features

* Responsive Portfolio Design
* About Me Section
* Academic Details Section
* Skills Showcase
* Projects Showcase
* Contact Information
* Welcome User Feature using JavaScript
* Dynamic Content Updates using DOM Manipulation
* Dark/Light Mode Toggle
* Modern UI with HTML, CSS, and JavaScript

## Technologies Used

* HTML5
* CSS3
* JavaScript

## JavaScript Functionality

* Accepts user input and displays a personalized welcome message.
* Implements a Dark/Light Mode toggle using DOM manipulation.
* Updates webpage content dynamically based on user interactions.
